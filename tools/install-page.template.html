Meme Coin Overlay

A Safari bookmark that drops a floating panel on any token page — contract address, one-tap copy, and jumps to every other terminal.

—

Install on iPhone

  1. Tap Copy bookmarklet above.

  2. In Safari, bookmark any page: share sheet → Add Bookmark.

    Name it OV — short, because you'll type it a lot.

  3. Open Bookmarks → Edit → tap OV.

    Clear the URL field completely, then paste.

  4. On a token page, tap the address bar and type OV.

    Pick the bookmark from the suggestions — the panel appears.

What it does today

  • Drag it anywhere; it remembers where you left it.
  • Reads the contract address off the URL, or off the page if the URL doesn't carry one.
  • Copy the CA with one tap.
  • Opens the same token on Axiom, GMGN, Dexscreener, Photon, Bullx, Solscan.
  • Follows you when Axiom or GMGN switches tokens without a page reload.

Notes

Tap the bookmark again to hide the panel, once more to bring it back. × removes it until you relaunch.

This is the skeleton. It exists so you can confirm the install works on your phone before the real feature set goes in. Every update after this means re-pasting the bookmark URL, so it's worth knowing the plumbing holds first.
